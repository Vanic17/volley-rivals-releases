# Volley Rivals

Versioni Windows dalla 0.38 in poi. Scarica il gioco da [Releases](https://github.com/Vanic17/volley-rivals-releases/releases).

Estrai lo ZIP in una nuova cartella e avvia Volley-Rivals.exe. Dalla 0.42 il menu Versioni e aggiornamenti permette di controllare le novita e scegliere una versione precedente. Il download si apre nel browser; installazione manuale. Tutti i partecipanti online devono usare la stessa versione.
